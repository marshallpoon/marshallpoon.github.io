SLAM · Computer Vision · ETH Zürich 2025

Research Project

Real-time Deployment of WildGS-SLAM

WildGS-SLAM is a monocular RGB SLAM system designed for dynamic environments using uncertainty-aware mapping and Gaussian Splatting techniques. This project focused on profiling bottlenecks, restructuring the pipeline, and optimising runtime performance to achieve real-time deployment.

Python C++ SLAM Gaussian Splatting

RL · Motion Planning · ETH Zürich

Hexapod RL Locomotion Controller

Implemented reinforcement learning-based motion planning for a hexapod robot in MuJoCo. Developed reward functions, tuned physics parameters for sim-to-real transfer, and achieved stable locomotion policies under randomised terrain and perturbation conditions.

Capstone · Embedded · UoM

Deployable Indoor Localisation System

Designed and built a real-time indoor positioning system using Ultra-Wideband ranging. Implemented a Time Division Multiple Access protocol in C++ firmware for multi-node coordination, running on embedded hardware over SPI and I2C with sub-10cm accuracy.
